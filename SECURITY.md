# Security Policy

## Scope

This project is a static, client-side HTML page. It has no backend, stores no user data and makes no authenticated requests. It loads Three.js and fonts from public CDNs.

## Reporting a vulnerability

If you find a security issue (for example an XSS vector or an unsafe third-party include), please **do not open a public issue**. Email **rajdipdharcode@gmail.com** with:

- A description of the issue
- Steps to reproduce
- The browser and OS you tested on

You can expect an acknowledgement within a few days and a fix or response as soon as practical.

## Supported versions

Only the latest version on the default branch is supported.
